# FT Security

Public security information for the **FT** protocol and its supporting systems

## Contents

- **[`KNOWN_ISSUES.md`](./KNOWN_ISSUES.md)** — issues already known to the FT team,
  sorted by system. **These are out of scope for the bug bounty.** Please review this
  list before submitting a report.

## Bug bounty

Before reporting, check **[`KNOWN_ISSUES.md`](./KNOWN_ISSUES.md)**. The issues listed
there are already known to the FT team and are **out of scope**.

All submission, eligibility, validity, and reward rules are governed by the **FT bug
bounty program on Sherlock**: https://audits.sherlock.xyz/bug-bounties/248. This
repository only documents the known issues; for what counts as a valid submission, refer
to the rules on the bounty platform.

## Reporting a vulnerability

Vulnerabilities are handled through the FT bug bounty program on **Sherlock**.
Please **follow the reporting instructions on the bounty platform** — do not open public
issues or pull requests for vulnerabilities.

- **Bug bounty (Sherlock):** https://audits.sherlock.xyz/bug-bounties/248
